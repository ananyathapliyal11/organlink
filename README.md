
# OrganLink

A Flask and MySQL application for blood and organ donor management,
inventory tracking, recipient requests, matching, and traceability.

## Requirements

- Python
- MySQL 8.0+
- Git

## Setup

1. Create a Python virtual environment.
2. Install packages using `pip install -r requirements.txt`.
3. Configure your local database credentials in `.env`.
4. Initialize the database using the agreed schema.sql.
5. Run the application using `python app.py`.

Never commit your .env file or database passwords.
